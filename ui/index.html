The chain replaces the bank, the board and the admin, not the trust. Circles are invite-only: members admit each other by vote, and any one member can veto. The random draw only stops a claimant picking their own vouchers.

Testnet prototype with test tokens; any real deployment needs legal review in each jurisdiction. Not insurance: nothing is promised, and gifts scale down when pots run low. Members need a NEAR wallet today; sponsored gas comes next.
